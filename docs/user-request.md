# طلب إنشاء أداة اختبارات ترقية ONYX

ابنِ أداة ويب خاصة وتفاعلية لتنفيذ اختبارات ترقية ONYX، بحيث تنظّم خطة الاختبار حسب النظام ثم الشاشة، ويكون لكل شاشة نموذج اختبار مستقل يغطي عملياتها التنفيذية الأساسية دون دمج شاشات متعددة. أضف تسجيل النتيجة الفعلية والحالة والملاحظات والأدلة، مع ملخص للتقدم والاختبارات المتعثرة وإمكانية التصفية والبحث. استخدم أسماء الشاشات الفعلية فقط من المواد المتاحة ولا تخترع أسماء. اجعل الواجهة عربية RTL وسهلة الاستخدام، ثم اختبر التدفقات الأساسية واستضفها بشكل خاص وقدّم رابطاً عاملاً دون توسيع صلاحية الوصول.

## إضافة إدارة المستخدمين والحقول والتهيئة

اريدك ان تضيف الى النظام
شاشة لادارة المستخدمين وصلاحياتهم
وكذلك ان تضيف محرر متقدم لكي اتمكن من اضافة الحقول والخانات الى نماذج الاختبارات ولكي اضيف خانات لمدخلات المستخدم مثل رقم الوثيقة التي تم انشائها في النظام او رقم الوثيقة المرتبطة
وكذلك واجهة خاصة بتهيئة البيانات الاساسية لكل اختبار (بمعنى اسجل الطرف والمبلغ والعملة المحددة التي سيقوم باستخدامها لتنفيذ الاختبار)

## تصحيح اسم المختبر وتطوير المحرر الشامل

اجعل اسم المختبر هو المستخدم. أريد المحرر أن يحرر كل الحقول في النموذج وليس فقط إضافة حقول إضافية. الحقول الإضافية لم تظهر، ولا يظهر في محرر النماذج الاختبار المراد تهيئته لإضافة الحقول إليه. أريد تطوير النظام إلى أعلى درجة.
